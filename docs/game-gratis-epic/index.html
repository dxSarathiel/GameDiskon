Kapan game gratis Epic berganti?

Epic Games Store mengganti game gratisnya seminggu sekali, biasanya hari Kamis malam waktu Indonesia. Minggu ini pergantiannya Kamis pukul 22.00 WIB. Jamnya bisa bergeser satu jam saat Amerika Serikat berganti jam musim panas. Setelah lewat batas waktunya, game kembali ke harga normal dan tidak bisa diklaim lagi.
