Info Game

Info Game berisi kabar seputar harga, sale, dan game gratis di Steam dan Epic Games Store, khusus untuk pemain di Indonesia. Ada tiga jenis tulisan di sini:

  • Laporan harga mingguan, terbit setiap Senin. Isinya game yang turun harga, naik harga, dan yang sedang di harga termurahnya, dihitung dari pantauan harga harian kami dalam Rupiah.
  • Game gratis Epic, terbit begitu Epic mengumumkan game gratis untuk minggu berikutnya, lengkap dengan jadwal klaim dalam WIB.
  • Kabar mingguan, terbit setiap Minggu dan ditulis langsung oleh pengelola GameDiskon, berisi kabar game pilihan minggu itu beserta pendapat kami.
