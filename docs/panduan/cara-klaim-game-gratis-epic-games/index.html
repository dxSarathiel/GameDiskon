Cara Klaim Game Gratis di Epic Games Store Setiap Minggu

Ditulis oleh Sarathiel, 27 September 2026.

Setiap minggu, Epic Games Store membagikan satu atau lebih game PC secara gratis. Bukan versi uji coba dan bukan pinjaman: sekali kamu klaim, game itu masuk ke library akunmu dan jadi milikmu selamanya, walaupun setelah promonya selesai harganya kembali normal.

Masalahnya, waktu klaimnya terbatas, sekitar satu minggu. Kalau terlewat, game itu kembali berbayar. Panduan ini menjelaskan jadwalnya dalam WIB, cara klaim langkah demi langkah, dan kebiasaan kecil supaya kamu tidak pernah ketinggalan.

Kapan game gratis Epic berganti?

Game gratis Epic berganti setiap hari Kamis pukul 11.00 waktu New York. Karena Amerika Serikat memakai jam musim panas, waktunya di Indonesia bergeser dua kali setahun:

  • Sekitar pertengahan Maret sampai awal November: Kamis pukul 22.00 WIB.
  • Sekitar awal November sampai pertengahan Maret: Kamis pukul 23.00 WIB.

Untuk WITA tambahkan satu jam, dan untuk WIT tambahkan dua jam. Jadi, patokan paling mudah: setiap Kamis malam, cek Epic Games Store. Saat itu game minggu lalu berhenti gratis dan game baru mulai bisa diklaim.

Yang perlu disiapkan

  1. Akun Epic Games. Pendaftarannya gratis di situs Epic Games. Kamu juga bisa masuk memakai akun Google, Steam, PlayStation, Xbox, atau Nintendo.
  2. Autentikasi dua faktor (2FA). Epic meminta 2FA aktif untuk klaim game gratis. Aktifkan lewat menu Account → Password & Security di situs Epic. Selain jadi syarat, 2FA juga melindungi akunmu yang isinya akan terus bertambah.

Kamu tidak perlu memasukkan kartu kredit atau metode pembayaran apa pun untuk klaim game gratis.

Cara klaim lewat browser (PC atau HP)

Cara ini paling praktis karena tidak perlu memasang aplikasi apa pun, dan bisa dilakukan dari HP sambil rebahan. Tampilan toko Epic umumnya berbahasa Inggris, jadi nama tombol di bawah ditulis sesuai yang muncul di layar.

  1. Buka store.epicgames.com dan masuk ke akunmu.
  2. Gulir ke bagian Free Games di halaman utama toko.
  3. Pilih game yang berlabel Free Now (bukan "Coming Soon", yang itu baru bisa diklaim minggu depan).
  4. Klik Get. Di jendela pembayaran, pastikan totalnya Rp 0 atau Free, lalu klik Place Order.
  5. Selesai. Game sudah tercatat di library akunmu.

Kamu tidak harus langsung mengunduh game-nya. Yang penting diklaim dulu sebelum batas waktunya. Game bisa diunduh kapan saja nanti lewat aplikasi Epic Games Launcher di PC.

Cara klaim lewat Epic Games Launcher

Kalau aplikasi Epic Games Launcher sudah terpasang di PC:

  1. Buka launcher dan pilih menu Store.
  2. Gulir ke bagian Free Games, lalu pilih game yang berlabel Free Now.
  3. Klik Get, lalu Place Order di jendela pembayaran.
  4. Game muncul di menu Library dan bisa langsung diunduh.

Supaya tidak pernah ketinggalan

  • Jadikan Kamis malam sebagai jadwal rutin. Pasang pengingat berulang di HP setiap Kamis pukul 22.00 WIB (atau 23.00 WIB saat bulan November sampai Maret).
  • Klaim semua game gratis, walaupun belum tertarik. Klaim tidak memakan ruang penyimpanan dan tidak ada ruginya. Siapa tahu setahun lagi kamu ingin memainkannya, dan saat itu harganya sudah kembali normal.
  • Ikuti kabar harian. Channel Telegram kami mengirim info game gratis Epic yang baru, lengkap dengan batas waktu klaimnya, dan beranda GameDiskon selalu menampilkan game gratis yang sedang berlaku.
  • Waspadai akhir tahun. Menjelang Natal dan Tahun Baru, Epic biasanya mengadakan event game misteri dengan game gratis yang berganti setiap hari, bukan setiap minggu. Di periode ini, cek setiap hari.

Pertanyaan yang sering muncul

Apakah game gratis Epic benar-benar jadi milik saya selamanya?

Ya. Setelah diklaim, game tetap ada di library akunmu walaupun promonya sudah selesai. Kamu bisa menghapus lalu mengunduhnya lagi kapan saja tanpa bayar.

Saya lupa klaim, apakah masih bisa didapat?

Tidak. Setelah batas waktunya lewat, game kembali ke harga normal. Epic jarang menggratiskan game yang sama dua kali, jadi sebaiknya jangan ditunda.

Kenapa tombol Get tidak muncul?

Pastikan kamu sudah masuk ke akun dan 2FA sudah aktif. Kalau game tertulis sudah ada di library, berarti kamu sudah pernah mengklaim atau membelinya. Sesekali, game gratis tertentu juga tidak tersedia untuk semua negara.

Apakah game gratis Epic bisa dimainkan di HP?

Umumnya tidak, karena sebagian besar game gratis mingguan adalah game PC. Epic sesekali juga membagikan game gratis untuk Android lewat aplikasi Epic Games Store, tapi ketersediaannya bisa berbeda di tiap negara.
